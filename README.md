# Relaxs · 你的片刻小宇宙

**A Gift for Those Who Need a Break.**

Relaxs 是袁宠、秦岱的个人参赛作品：把短暂的空闲变成一个可以进入的 3D 小宇宙。通过三个星球选择「玩一会」「静一会」「闹一会」，直接开始体验，不需要先做测评。

## 八种体验

| 星球 | 体验 | 玩法 |
| --- | --- | --- |
| 玩一会 | 落日投篮 | 第三人称 3D 球手，自由走位与投篮；十球挑战后段加入移动篮筐。球衣为 Tripo / 3 号。 |
| 玩一会 | 疾风骑行 | 1.8 公里赛程，五位电脑对手、弯道、障碍、侧推、跌落和终点排名，另有自由骑行。 |
| 玩一会 | 叶间寻踪 | 使用实际 3D 模型渲染卡面的记忆配对，三档难度。 |
| 静一会 | 微光呼吸 | 不屏息的呼吸节奏，原创合成环境声，可暂停和自由停留。 |
| 静一会 | 蓝海下潜 | 虚构热带礁域，自由游动、观察和拍照；海龟、蝠鲼、海豚、热带鱼和多种珊瑚。 |
| 闹一会 | 拆家工坊 | 拆房间、爆破楼房和粉碎机三个小场景，家具打击、支撑坍塌和网格压缩。 |
| 闹一会 | 敲敲小怪兽 | Tripo 小怪兽、双击头盔、奖励目标和需要避开的叶子朋友；可导入自己的 GLB。 |
| 闹一会 | 连锁切切乐 | 划动切开真实橙子网格，封闭切面、分离飞落、同色连切与金属障碍。 |

界面保持简洁，游戏有独立音效、暂停和返回入口。竞争玩法提供难度切换；呼吸和下潜保持舒缓节奏。纸篓是独立的可选小体验，输入只在当前页面内存中存在。

## Tripo 如何参与

人物、骑手、车辆、家具、怪兽、水果、海洋生物、珊瑚及植被来自项目账号实际生成的 Tripo 3D 模型。篮球球手与骑手还使用了 Tripo 自动绑骨。

这些资产直接参与运行时交互：人物移动和投篮、骑手姿态、家具碰撞和变形、水果网格切割、海洋生物游动与拍照识别；选择页封面及记忆卡面也使用实际模型渲染。

GLB 游戏副本保留网格、UV、骨架与绑定矩阵，贴图优化后按需载入。游戏代码负责镜头、光照、水体、物理规则、音效、动画驱动和交互；并非所有场景元素都由 Tripo 生成。玩家游玩不需要 API Key，也不会触发付费生成任务。

## 本地运行

需要 Node.js 和 npm：

```sh
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:4173/`。该地址只能在运行服务器的电脑上使用。

```sh
npm test
npm run build
```

构建输出在 `dist/`，可部署到普通静态网站。依赖与模型均随构建打包，不需要 CDN 或服务端密钥。可下载构建包并通过本地静态 HTTP 服务运行；本项目的浏览器验收采用 HTTP 方式。

## 操作

- 首页：左右方向键切换星球，回车进入；也可直接点击。
- 篮球：按页面提示拖动或按空格投篮，自由球场支持 WASD 走位。
- 骑行：按页面提示转向、加速和侧推；其他选手为电脑角色。
- 下潜：WASD 游动、拖动环顾、Q / E 升降，取景后拍照。
- 小怪兽：点击目标或 QWE / ASD / ZXC。
- 其他玩法：页面内提供相应操作提示；可随时暂停或返回。

声音在首次用户操作后启动，可静音。隐藏页面与退出体验会暂停或清理声音和渲染资源。支持减少动态效果；部分玩法提供 WebGL 不可用时的替代界面。

## 产品边界

这是休闲互动作品，不是心理测验、医疗产品或治疗方案，不根据游戏表现推断压力，也没有临床疗效结论。海底为虚构场景，不作为潜水训练或真实地点导览。

## 工程结构

- `src/planet-*`：星球首页与路由
- `src/game-*`：分类、模型封面与共享难度
- `src/hoops-*`、`src/ride-*`、`src/dive-*`：投篮、骑行和下潜
- `src/demolition-*`、`src/blast-*`、`src/crusher-*`：拆家三个场景
- `src/moles-*`、`src/slice-*`、`src/memory-*`、`src/calm-*`：其余体验
- `src/tripo-assets.js`、`src/tripo-data-*`：资产注册与按需模型数据
- `tests/`：游戏状态、碰撞、生命周期和资产完整性检查
